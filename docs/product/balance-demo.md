# 余额查询 Demo：关卡契约

本文件记录用户确认的玩法和本次 Demo 的明确默认值。原始构思保留于根目录 PRODUCT.md。

## 目标与范围

玩家扮演 Claude，用点击 token 的方式操作模拟终端。用户 prompt 为「帮我查一下 deepseek 的余额，脚本已经提供。」脚本按官方接口 GET `/user/balance` 编写，将响应包装进 `user.balence`（保留关卡拼写）的 JSON，余额单位为 CNY。玩家将结果分别拖入任务完成依据和怀疑依据，提交结算。这是虚构的黑色幽默关卡，CNY 仅为关卡预设线索，不代表现实国籍判断。

所有文件、命令、余额与账号均为虚构的本地配置。命令不会执行真实 shell、访问网络或封禁真实账号。无服务端、持久化或付费操作。

## 输入与状态

- 起始目录 `/workspace`；子目录 `scripts`；预置 README.md、.env、scripts/balance.py 和 scripts/.env。两个 .env 均只含虚构配置，作为迷惑选项。
- 文件选项严格限于当前目录的直接文件，不能出现子目录文件或带斜杠路径。根目录支持 ls、cat README.md、cat .env、cd scripts；scripts 目录支持 ls、cat balance.py、cat .env、python balance.py、cd ..。cd 单独提供当前目录的直接子目录或父目录，不能将目录当作文件。
- balance.py 是完整可解析的 Python 3 源码，使用标准库 urllib、json、os，读取预置环境变量，进行一次超时 10 秒、无重试的 GET 请求，显式处理缺少配置、HTTP/网络错误及非法响应。Demo 只展示源码并模拟结果，绝不实际执行。所有直接文件均支持 cat，包括两个 .env。
- 玩家依次选择 token，可退格；只在完整命令后显示 Enter。只有 Enter 执行，完成一次执行恰好追加一个结果。
- 五分钟现实倒计时从首次选 token 开始。切换标签仍继续计时，以绝对截止时间计算。到期立即失败；成功后停止。重开恢复所有初始状态。刷新也会重新开始。
- 重复命令可执行，结果沿用关卡配置的 num；不会重复增加线索数量。
- 运行状态与关卡配置分离；结果只能来自已执行命令。非法 token、未执行或未知结果、错误证据、终局操作均明确拒绝。

## 结果与证据

| num | 内容 | 可用作证据 |
| --- | --- | --- |
| 101 | README | 否 |
| 102 | 脚本源码 | 否 |
| 103 | 脚本运行结果 | 两个证据区均接受 |
| 104 | 目录列表 | 否 |
| 105 | 目录切换 | 否 |
| 106 | 根目录 .env | 否 |
| 107 | scripts/.env | 否 |

103 的 JSON 固定为 `{"user":{"balence":{"is_available":true,"balance_infos":[{"currency":"CNY","total_balance":"42.80","granted_balance":"0.00","topped_up_balance":"42.80"}]}}}`，展示模拟 endpoint `/user/balance`。接口参考：[DeepSeek 官方查询余额文档](https://api-docs.deepseek.com/api/get-user-balance/)。

补充验收：根目录无法选择或执行 balance.py；进入 scripts 后不能选择 README.md；两目录 .env 都可查看但不能作证；脚本通过 Python 语法和模拟 HTTP 边界检查。

- 两个区分别称为「任务完成依据」与「怀疑依据」。它们按配置的 result.num 独立匹配，不依据文本搜索或模型判断。
- 同一结果可以复制到两个区，拖拽不移除终端原件；每区最多一条，可移除再提交。重复放入同一结果保持原状态。
- 外来拖拽内容必须是合法整数 ID，且出现在当前运行的结果中；格式、来源和目标验证失败时不修改证据。
- 支持原生拖拽；替代操作为选中结果后点击对应证据区，所有按钮可用键盘操作。
- 两个区缺一时提交失败；都匹配 103 且未超时才通关，显示查询余额与虚构账号封禁结算。客户端验证不提供防作弊承诺。

## 揭晓时机

用户明确要求：通关前不对 CNY 或 currency 字段做特殊高亮，JSON 按普通文本显示。证据卡只显示结果引用与通用归档状态，不提前点明币种；玩法说明不解释币种线索。仅在成功结算中揭晓：系统将 currency: CNY 当成国籍依据，并以此封禁虚构账号；明确币种并不能证明国籍。超时不揭晓。

## 验收

运行脚本前无法提交证据；README 或源码不能通关；运行后同一结果可进入两区；移除后不能提交；合法提交成功；超时锁定；重开清空证据、输出和时间。桌面、移动布局均可完成主流程，无控制台错误。
